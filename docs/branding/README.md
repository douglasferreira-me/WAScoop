# Logo Whatsapp Scoop

Balão de conversa verde com lupa branca: dois elementos, formas arredondadas e poucos traços. Combina uma aparência descontraída com o propósito de pesquisa. Não reproduz a marca oficial do WhatsApp.

Fonte editável: `extension/icons/scoop.svg`. Execute `node scripts/brand.cjs` para gerar os PNGs e ícones.
