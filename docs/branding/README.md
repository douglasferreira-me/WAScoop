# Logo Whatsapp Scoop

Uma carinha de pesquisador de óculos, sorrindo dentro de um balão verde. Dois elementos SVG, uma cor e poucos traços arredondados: aparência descontraída, legível e adequada ao propósito de pesquisa. Não reproduz a marca oficial do WhatsApp.

Fonte editável: `extension/icons/scoop.svg`. Execute `node scripts/brand.cjs` para gerar os PNGs e ícones de 16 a 512 pixels. A versão 0.1.4 atualiza somente a identidade visual; os recursos de coleta são os da versão 0.1.3.
