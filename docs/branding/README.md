# Logo do Whatsapp Scoop

O mascote é um **balão pesquisador**: olhos curiosos, um sorriso discreto e óculos cujo lado maior também é uma lupa. Ele aproxima a conversa da investigação acadêmica sem tratar mensagens como culpadas ou verificadas de antemão. O pequeno brilho representa uma descoberta; as marcas na base lembram registros de dados.

As cores principais são verde escuro `#075e54`, verde vivo `#25d366` e branco esverdeado `#f5fff8`, com um detalhe dourado `#ffd166` para dar personalidade.

- Fonte vetorial editável: `extension/icons/scoop.svg`.
- Logo para GitHub e divulgação: `docs/branding/logo.png` (512 × 512).
- Ícones da extensão: PNGs de 16, 32, 48, 96, 128, 256 e 512 pixels, em `extension/icons/`.

O desenho é original do projeto; não usa o símbolo oficial do WhatsApp. Os arquivos seguem a licença GPL-3.0 do repositório. Execute `node scripts/brand.cjs` após `npm ci` para regenerar os PNGs. O empacotamento já realiza essa etapa automaticamente.
